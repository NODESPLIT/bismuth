# Bitwise Operators

---

##### Bitwise `&` AND between numbers

###### Example:
```
7 & 4
```
```
=> 4
```

---

##### Bitwise `|` OR between numbers

###### Example:
```
7 | 4
```
```
=> 7
```

---

##### Bitwise `^` XOR between numbers

###### Example:
```
7 ^ 4
```
```
=> 3
```

---

##### Bitwise `~` NOT on a number

###### Example:
```
~4
```
```
=> -5
```

---

##### Bitwise `<<` LEFT SHIFT between numbers

###### Example:
```
5 << 2
```
```
=> 20
```

---

##### Bitwise `>>` RIGHT SHIFT between numbers

###### Example:
```
16 >> 2
```
```
=> 4
```
